# HyperFrames 텍스트 모션 라이브러리

github.com/heygen-com/hyperframes 의 `registry/`에서 텍스트·타이포그래피 관련 항목만 골라 오프라인으로 복사한 것입니다(Apache 2.0, `LICENSE` 참고).
각 폴더에는 다음이 들어 있습니다.
- `registry-item.json`: 바꿀 수 있는 값(문구, 색 등)과 설치 위치
- 효과 본체 HTML
- 미리보기용 `demo.html`

**넣는 방법:** `hyperframes-registry` 스킬을 따릅니다. 블록은 하위 장면(sub-composition)으로 넣고, 컴포넌트는 코드 조각을 기존 장면에 합칩니다. 인터넷이 되면 `npx hyperframes add <이름>`으로도 설치할 수 있습니다.
