# 최종 점검 순서

초안을 다 쓴 뒤 이 순서로 한 번 읽는다. 점검 과정이나 결과를 사용자에게 보고하지 않고, 고친 글만 낸다. 사용자가 "어디를 고쳤는지 보여줘"라고 하면 그때만 전후 대조를 붙인다.

## 1단계: 처음과 끝 (30초)

- [ ] 첫 문장이 예고·인사·메타 발화인가? → 지우고 둘째 문장부터 다시 읽는다.
- [ ] 마지막 문장이 교훈·희망·다짐·아포리즘인가? → 마지막 사실이나 장면, 다음 행동으로 바꾼다.
- [ ] 제목이 "~의 모든 것", "~하는 N가지 방법", "~, 이제는 ~할 때", "당신이 몰랐던 ~"인가? → 주제가 바로 보이는 제목으로.

## 2단계: 공식 검색 (눈으로 훑기)

아래 표현을 찾아 하나씩 처리한다.

- [ ] 아니라 / 넘어 / 그치지 않고 → 대구 공식인지 확인
- [ ] 바로 / 진정한 / 핵심은 / 본질 / 결국 / 무엇보다 → 각 1회 이하
- [ ] 통해 / 있어서 / 대한 / 인해 / 의해 / 되어지 / 가지 → 번역투 교정표
- [ ] 다양한 / 여러 / 많은 / 수많은 → 셀 수 있으면 센다
- [ ] 중요하다 / 필요하다 / 필요가 있다 → 직접 지시로
- [ ] 수 있을 것 / 것으로 보 / 라고 할 수 → 헤지 1~2회로 줄이기
- [ ] 줄표(—), 콜론(:), 이모지, 볼드 → 개수 세고 줄이기
- [ ] 또한 / 뿐만 아니라 / 나아가 / 이처럼 / 이를 통해 / 그리고(문두) → 문단당 1회 이하

## 3단계: 리듬 (소리 내 읽는다고 상상)

- [ ] 연속 세 문장의 길이가 비슷한 곳 → 하나를 자르거나 붙인다.
- [ ] 같은 어미가 세 번 이어지는 곳 → 하나를 바꾼다.
- [ ] 셋씩 나열한 곳 → 하나를 빼거나 하나를 더한다.
- [ ] 문단 길이가 모두 비슷한가 → 하나는 짧게.
- [ ] 숨이 차는 문장(80자 이상, 쉼표 셋 이상) → 둘로.

## 4단계: 내용

- [ ] 고유명사·숫자·날짜·감각 디테일이 문단마다 하나 이상 있는가(장르상 필요한 경우)?
- [ ] 출처 없는 일반론("전문가들은", "연구에 따르면")이 있는가?
- [ ] 내가 지어낸 숫자·인용·사례가 있는가? → 있으면 지우거나 [확인 필요] 표시.
- [ ] 필자의 판단이 드러나는가, 아니면 양쪽을 다 들어주고 끝나는가?

## 5단계: 목소리

- [ ] 존댓말·반말, 문어·구어가 한 글 안에서 섞였는가?
- [ ] 매체별 스킬의 톤과 맞는가?
- [ ] 사용자가 준 원고라면, 필자의 고유한 표현을 일반형으로 바꿔버리지 않았는가?

## 마지막 시험

아무 문단이나 하나 골라, 이 문장을 사람 기자나 편집자가 마감 직전에 썼다고 상상한다. 그 사람이 이렇게 썼을 법한가. 아니라면 그 문단을 다시 쓴다.
