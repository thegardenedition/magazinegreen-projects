# 번역투·일본어투·군더더기 교정표

AI 한국어의 상당 부분은 영어 문장 구조를 한국어 단어로 옮긴 모양이다. 이오덕, 이수열, 김정선이 수십 년 지적해 온 일본어투·번역투와 겹친다.

## 1. 조사·어미 번역투

| 번역투 | 고친 꼴 |
|---|---|
| ~를 통해 (through) | ~로, ~해서, ~하며 |
| ~에 있어서 (in ~ing) | ~에서, ~할 때 (대개 지운다) |
| ~에 대한/대해 (about) | ~의, ~를 (지워도 되는지 먼저 본다) |
| ~로 인해 (due to) | ~ 때문에, ~해서 |
| ~에 의해 (by) | 능동문으로: "A에 의해 설계됐다" → "A가 설계했다" |
| ~함에 있어 | ~할 때 |
| ~을 가지다 (have) | 있다: "의미를 가진다" → "의미가 있다" |
| ~을 갖고 있다 | ~이 있다, ~하다 |
| ~에 위치한 (located in) | ~에 있는 |
| ~하는 중이다 (be ~ing) | ~하고 있다, ~한다 |
| 가장 ~한 ~ 중 하나 (one of the most) | 손꼽히는, 대표적인, 또는 하나를 특정 |
| ~할 필요가 있다 (need to) | ~해야 한다, 직접 지시 |
| ~에도 불구하고 | ~인데도, ~지만 |
| ~와 함께 (with) 남발 | 지우거나 "~하고" |
| ~로부터 | ~에서, ~에게서 |
| 만약 ~라면 | ~라면 ("만약" 삭제) |
| ~하기 위해서 | ~하려고 |
| ~으로써/~으로서 혼동 | 수단은 ~으로써, 자격은 ~으로서 |

## 2. 일본어투

| 일본어투 | 고친 꼴 |
|---|---|
| ~에 다름 아니다 | ~이다, ~와 같다 |
| ~에 값하다 | ~할 만하다 |
| ~의 ~의 ~ (の 연쇄) | 조사를 바꾸거나 동사로 풀기: "정원의 설계의 원칙" → "정원을 설계하는 원칙" |
| ~에 있다 (である) "문제는 ~에 있다" | "문제는 ~이다" |
| 보다 (より) 비교부사 "보다 나은" | 더: "더 나은" |
| ~적(的) 연쇄 | 동사·형용사로 풀기 |
| 미연에, 견지에서, 입장에서 | 미리, ~로 보면, ~로서는 |
| 가일층, 제반, 상기 | 더욱, 여러, 위 |

## 3. 피동 남발

- "~되어지다", "~지게 되다", "보여지다", "생각되어지다"는 이중 피동이다. "~된다", "보인다", "생각한다".
- 행위자가 분명하면 능동으로. "이 정원은 2019년에 조성되었다" → "2019년에 OO이 이 정원을 만들었다".
- "~되었다"가 한 문단에 세 번 넘으면 능동으로 바꿀 문장을 찾는다.

## 4. 명사화 (동사를 명사로 바꿔 쌓기)

| 명사화 | 동사로 |
|---|---|
| 배수 문제의 해결을 위한 방안 마련 | 물이 잘 빠지게 하는 방법 |
| 관리 효율성의 제고 | 관리를 쉽게 함 |
| ~을 진행하다/실시하다/시행하다 | 그냥 그 동사: "인터뷰를 진행했다" → "인터뷰했다" |
| ~에 대한 검토가 이루어졌다 | ~을 검토했다 |
| ~하는 것이 가능하다 | ~할 수 있다 |

## 5. 김정선의 네 가지 군더더기: 적·의·것·들

- **적**: "역사적 맥락" 정도는 괜찮다. "효과적, 체계적, 전략적"이 한 문단에 둘 이상이면 푼다.
- **의**: 한 명사구에 "의"가 둘 이상이면 하나를 없앤다.
- **것**: "~하는 것은 ~하는 것이다"는 둘 다 지울 수 있는지 본다. "중요한 것은 물빠짐이다" → "물빠짐이 먼저다".
- **들**: 한국어는 복수 표지를 생략해도 된다. "많은 사람들" → "많은 사람", "나무들이" → "나무가".

## 6. 대명사

- "그녀"는 문어 번역투다. 이름이나 직함을 다시 쓴다.
- "그것은", "이것은"으로 문장을 시작하지 않는다. 가리키는 명사를 쓰거나 생략한다.
- "우리"를 습관적으로 넣지 않는다("우리의 삶", "우리 모두").

## 7. 띄어쓰기·표기 기본

- 의존명사 띄움: 할 수 있다, 한 지 사흘, 아는 바, 먹을 만하다.
- 단위 띄움: 3 m가 원칙이나 매체 관행상 3m 붙여쓰기 허용. 한 글 안에서 통일.
- 외래어는 국립국어원 외래어 표기법. 학명은 이탤릭, 국명 먼저 쓰고 학명은 처음 한 번 괄호.
- 숫자: 열 이하는 한글(셋, 다섯), 그 이상은 아라비아 숫자가 신문 관행. 매체 스타일북이 있으면 그쪽을 따른다.
