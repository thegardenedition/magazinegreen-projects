# 출처

https://github.com/lemomo-ai/lemo-opuscar 의 텍스트 가이드를 오프라인 참고용으로 복사한 것입니다
(원본 커밋 fdc46d7, MIT 라이선스 — `../LICENSE` 참고).

스킬 자체는 실행할 때 `scripts/setup.sh`로 최신 라이브러리 전체를 내려받습니다.
렌더링 코드, 폰트, 3D 소재, 데모 영상·이미지는 여기에 복사하지 않았습니다.

함께 들어 있는 것:
- `opuscar98/` — OPUSCAR 98의 작품별 스타일 프롬프트 98종 (`STYLES.md` 목록, `styles.json` 전체 데이터)
- `styles/catalog.json` — 라이브러리 스타일 43종의 갤러리 목록과 용도
