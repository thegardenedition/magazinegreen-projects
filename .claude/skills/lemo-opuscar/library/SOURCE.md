# Source

Offline reference copy of the text guides from https://github.com/lemomo-ai/lemo-opuscar
(commit fdc46d7, MIT License — see ../LICENSE).

The skill itself fetches the full, up-to-date library at runtime via `scripts/setup.sh`.
Code, fonts, 3D assets and demo media are not copied here.

Also included: `opuscar98/` — the 98 per-film style prompts from OPUSCAR 98 (`STYLES.md` index, `styles.json` full data),
and `styles/catalog.json` (the 43-style gallery catalog with use cases).
