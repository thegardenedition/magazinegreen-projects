# 실사 영상 + 자막·그래픽 합성

출처: herk-edit-kit, claude-video-edit, heditor, ffmpeg-skill, TK-koubo-video, video-shotcraft, mrpaidsocial(라이선스 없음 — 아이디어만), appariciojunior(비상업 — 아이디어만). 약칭과 라이선스는 `sources.md`.

## 1. 파이프라인 (잘 만든 저장소들이 모두 같은 구조로 수렴했다)

1. **프로브**: `ffprobe`로 길이·fps(가변 프레임?)·해상도·회전 태그·HDR(HLG/PQ)·오디오 채널(한쪽 채널만 목소리?).
2. **전사(단어 타임스탬프)**: `ffmpeg -i in.mp4 -ac 1 -ar 16000 -c:a pcm_s16le a.wav` → faster-whisper `large-v3`, `word_timestamps=True, condition_on_previous_text=False`. 한국어에 `.en` 모델 금지.
3. **Claude는 무엇을 남길지 단어 번호로 결정**, 스크립트가 컷 위치를 음성 에너지로 다듬고 프레임에 맞춘다. 생성된 컷 파일을 손으로 고치지 않는다.
4. **원본 기준 EDL 하나**. 자막·그래픽·효과음 시간은 EDL로 환산. 잘린 파일을 다시 자르지 않는다.
5. 그래픽은 결정적 타임라인(Remotion/HTML+GSAP)으로, 발화 단어에 고정.
6. 합성(아래 3장) → 오디오 한 번에 믹스·마스터 → 영상은 스트림 복사로 먹스.
7. **검증은 렌더된 파일로**. 새 버전은 새 파일 이름.
8. 사람의 피드백은 스킬의 규칙으로 영구히 적는다.

## 2. 컷 편집 수치

- Whisper 단어 끝은 쉼 속으로 0.1~0.4s 넘어간다 → 컷 지점은 에너지 엔벨로프(10~50ms RMS)에서 찾는다.
- 남기는 쉼: 차분한 영상 0.35s, 빠른 쇼츠 0.15s. 문장 끝(.!?) 뒤 0.20s, 그 외 0.14s.
- 머리 0.08~0.10s 앞, 꼬리 0.12~0.16s 뒤 여유. 파열음(ㅌㅋㅍ) 끝 10~120ms는 살린다.
- 이음마다 4ms 페이드인/15ms 페이드아웃(딸깍 소리 방지).
- 반복 테이크는 끝까지 매끄러운 마지막 테이크를 남긴다. 확신 없으면 남기고 표시.
- 목소리 속도·음높이를 바꾸지 않는다. 문장 안 어순을 바꾸거나 하지 않은 말을 이어 붙이지 않는다.
- 점프컷 확대: 같은 장면 안에서 100% ↔ 107.5% 번갈아, 결정적 한 마디에만 115% 펀치인.
- 쇼츠 리듬: 평균 샷 1.1~1.4s, 2.8s 넘는 샷 없음, 첫 컷 0.6~1.0s(첫 핵심어), 1~2초마다 그림 하나, 5~8초마다 레이아웃 변화.
- 함정: 구간별 AAC 인코딩 후 이어 붙이기 금지(이음마다 ~50ms씩 밀림). 영상·음성을 다른 반올림으로 자르지 않는다.

## 3. 자막 위 얹기

- 덩어리: 쇼츠 1~3어절, 대화 3~5, 차분 4~6. 쉼 150ms 이상이나 문장 끝에서 끊는다.
- 시간: 첫 단어 2프레임 전 등장, 다음 덩어리 시작 −0.04s까지 유지. 두 자막이 겹치지 않게 반드시 끈다.
- 크기: 1080 세로 기준 유효 높이 56px 이상(화면 높이 5.2%), 보조 32px 이상. 휴대폰 폭 360~480px에서 확인.
- 가독성: 흰 글자 + 0.08~0.12em 외곽선 또는 어두운 판(가장 확실). 외곽선은 실제 렌더러에서 시험한다(Chromium에서 `-webkit-text-stroke`가 깨지는 경우가 있어 `paint-order: stroke fill` 또는 겹친 text-shadow).
- 얼굴(눈·입·턱) 위 금지. 컷을 넘는 자막은 컷 프레임에서 새 위치로.
- 충실도: 매거진그린 인터뷰는 말 그대로(오인식된 이름만 수정), 채널그린 쇼츠는 군더더기만 뺀 정리본. 어느 쪽도 하지 않은 말을 만들지 않는다.
- 내레이션을 화면에 그대로 옮기지 않는다 — 화면 글자는 구조·숫자·근거를 맡는다.

## 5. 합성 경로

1. **그래픽만 알파로 렌더 → ffmpeg 합성** (긴 원본에 권장)
   - ProRes 4444: `-c:v prores_ks -profile:v 4 -vendor apl0 -pix_fmt yuva444p10le -alpha_bits 16`
   - VP9 알파: `-c:v libvpx-vp9 -pix_fmt yuva420p -crf 20 -b:v 0 -auto-alt-ref 0 -metadata:s:v:0 alpha_mode=1`
   - Remotion: `npx remotion render ... --codec=prores --prores-profile=4444 --pixel-format=yuva444p10le` (투명 배경)
   - 합성: `ffmpeg -i footage.mp4 -c:v libvpx-vp9 -i gfx.webm -filter_complex "[0:v][1:v]overlay=0:0:shortest=1:format=auto,format=yuv420p" ...`
   - **VP9 알파를 읽을 땐 `-c:v libvpx-vp9`를 그 `-i` 앞에.** ffmpeg 기본 VP9 디코더는 알파를 버린다. H.264는 알파가 없다.
2. **원본을 Remotion 안에 넣기** (짧은 클립): 넣기 전 `ffmpeg -i in.mp4 -c:v libx264 -g 30 -keyint_min 30 -crf 18 -c:a aac in_seek.mp4`로 키프레임을 촘촘히. 영상 요소가 아니라 감싼 래퍼를 움직인다.
3. **ASS 자막 굽기** (그래픽 없는 단순 자막): libass. 크롭·리사이즈 → 자막 → 출력 순서(반대면 화면 밖으로 나가거나 흐려진다).

색: RGB 그래픽은 BT.709로 명시 변환(ffmpeg 기본 BT.601). Chrome 스크린샷·Remotion JPEG는 전체 범위 → `scale=in_range=full:out_range=tv`. 로그 촬영본이 아닌 영상에 로그 LUT 금지. HDR(HLG) 원본은 그래픽을 SDR로 만든 뒤 변환하거나 SDR로 톤매핑.

## 6. 오디오

- 라우드니스: 최종 스테레오 파일에서 −14 LUFS, 트루피크 −1 dBTP(AAC 인코딩 뒤엔 −1.5). 2패스 `loudnorm=I=-14:TP=-1.5:LRA=9`.
- 목소리: 기본은 선형 게인 하나 + 필요하면 80Hz 하이패스. 노이즈 제거·컴프레서는 A/B로 확인 후(과하면 물속 목소리).
- 음악: 말이 빽빽하면 말 아래 ~21dB, 광고·트레일러 성격이면 ~15dB. 말 사이·B롤에서 올린다. 사이드체인 덕킹 예: `sidechaincompress=threshold=0.05:ratio=4:attack=20:release=400`.
- 효과음: 보이는 동작에만. 강조 단어 50~120ms 앞. 컷마다 휘익 금지. 효과음 파일의 시작이 아니라 내부 피크를 맞춘다.

## 7. B롤·오버레이

- B롤 길이: 컷어웨이 2~4s, 전환 시퀀스 6~8s. 한 쇼츠에서 같은 B롤 두 번 금지. 모든 샷은 움직인다.
- 하단 자막(이름·직함)은 초반 한 번. 카드는 피사체보다 어둡게.
- 화면 속 작은 UI를 빈 공간에 띄우지 않는다. 읽혀야 하는 화면 글자는 24px 이상이 되도록 확대.
- 인물 뒤에 글자 넣기(깊이 합성): 인물 분할 알파(예: MediaPipe) → 배경 → 뒤 그래픽 → 알파 인물 → 앞 그래픽. 색 보정은 원본 판에, 알파 컷아웃에 하지 않는다.
