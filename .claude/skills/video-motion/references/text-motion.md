# 텍스트 모션 카탈로그

공개 영상 스킬들의 패턴을 모아 한국어·두 매체에 맞게 다시 적었다. 숫자는 30fps 기준(f = 프레임). 출처 약칭은 `sources.md` 참고. 실측값이 있는 출처(apple-motion: 애플 리캡 영상 6편 33,187프레임 측정, motionmaxxing: 전문가 클립 53개 측정)를 우선했다.

## 1. 기본 장치 (매거진그린 기본값 ★)

| 패턴 | 만드는 법 | 수치 | 어울리는 곳 |
|---|---|---|---|
| ★ 마스크 밀어 올리기 | 어절마다 overflow:hidden 칸, 안쪽 translateY 112%→0 (+회전 4°→0, 아래-왼쪽 기준) | 14~16f, 어절 간격 3~5f, 감속 (0.16,1,0.3,1) | 매거진그린 제목 전반 |
| 어절 빌드(말 리듬) | 어절이 통째로 화면높이 3~7% 아래에서 올라오며 흐림이 걷힘, 튕김 없음 | 빠른 훅 2~4f 간격 / 표준 4~6f / 내레이션 따라 8~12f 불규칙. 결정적 단어 앞은 간격 1.5~2배 | 양쪽 매체 |
| 어절 페이드+상승 | 불투명도, translateY (1−p)·22px, 흐림 3px→0 | 등장 12~16f, 간격 5~7f, 퇴장 8~10f(+어절당 2f, 위로 36px, 가속) | 채널그린 보조 줄 |
| 크게 시작해 줄어들기(한 번만) | 첫 단어가 1.4~2배(흐림 포함)에서 감속하며 제자리 | 0.3s 안에 86% | 영상의 논지 한 단어 |
| 자간 좁혀 들어오기 | letter-spacing 0.5em→−0.03em + 흐림, 하나의 스프링(ζ≈0.95) | ~1.0s, 0.3s에 80% | 4~8자 영문 라벨(한글은 효과 약함) |
| 슬롯/단어 교체 | 고정 어간 + overflow:hidden 칸에서 단어가 위로 빠지고 아래서 올라옴 | 칸당 6~8f, 마지막은 살짝 넘치는 스프링 | "봄을/여름을/…/사계절을" |
| 줄 누적 | 새 줄이 28px 올라오며 들어오고 이전 줄은 불투명도 0.3으로 물러남 | 0.3s 감속 | 생각의 전개 |
| 진행형 밝힘(카라오케 문단) | 한 덩어리 전체를 30%로 깔고 말하는 어절이 0.09s 먼저 100%로 | 한 카드 16어절 이하 | 내레이션 있는 해설 |
| 숫자 카운트 | 프레임마다 감쇠 계단 15~23개 값, 0.5~0.9s, 고정폭 숫자. 넘치지 않음 | 착지 후 0.5~1.2s 유지, 단위는 0.2s 뒤 | 채널그린 수치(출처 있는 것만) |

## 2. 강조 장치 (영상당 하나만 고른다)

| 장치 | 수치 |

| 색 하나(이끼색 #C8DB86) | 도착 순간 강조색 0.13~0.28s 후 본색으로 돌아오거나, 끝까지 유지 |
| 형광 띠 | 글자 아래쪽 40~50% 높이 띠, 왼쪽에서 scaleX 0→1 0.4~0.6s, 불투명 35~60%, 좌우 6~8px 넘침. 문장이 다 읽힌 뒤 시작 |

## 4. 전환

- 기본은 하드 컷(애플 측정 92%). 컷은 움직임이 가장 빠른 프레임에서, 양쪽 방향·속도를 맞춘다.
- 슬라이드쇼처럼 보이지 않게: 컷마다 이어지는 물체·카메라 이동·모핑·다음 장면의 바닥이 되는 효과 중 하나.
- 밀어 들어가기: 나가는 쪽 1→1.2배, 들어오는 쪽 0.75→1배. 반대 방향을 섞지 않는다.
- 피할 것: 장면 사이 크로스페이드(회색으로 뭉갬), 매번 같은 전환, 들어올 방향으로 나가는 글자.

## 5. 한국어 조판 규칙

- 서체: 제목 Noto Serif KR 700~900(매거진그린), 본문·라벨 Pretendard 400~700. 채널그린은 Pretendard 단독(제목 700~800). 둘 다 OFL — `mg-shorts/public/fonts`에 들어 있다.
- 자간: 큰 제목 −0.03~−0.04em, 본문 0, 영문 대문자 라벨 +0.14~0.2em. 한글 제목에 양(+) 자간은 현수막처럼 보인다.
- 행간: 제목 1.15~1.22, 보조 1.3.
- 줄 길이: 한 줄 15자 안팎(자막), 큰 제목은 한 줄 7~9자 이하로 끊는다. 의미 단위로 끊고 조사만 다음 줄로 넘기지 않는다.
- 문장부호: 마침표는 앞 어절에 붙여 같이 움직인다(어절 분리 시 공백 기준이라 자동으로 붙는다). 마침표 하나만 줄 끝에 남기지 않는다.
- 숫자+단위(64㎡, 2년)는 한 덩어리로, 고정폭 숫자(`tabular-nums`).
- 한글 글리프는 라틴보다 3~7px 낮게 앉는다 — 영문과 섞을 땐 기준선을 눈으로 맞춘다.
- 읽는 속도: 화면 글자 초당 5~6음절 이하. 내레이션은 초당 4~5음절(mg-video-copy).

## 6. 리듬

- 이동 중앙값 10f. 이동·크기 12f, 불투명 6f, 흐림 7f.
- 등장은 느리고 단단하게, 퇴장은 빠르게(등장의 50~60%). 다음 요소는 앞 요소가 30~50% 진행됐을 때 출발.
- 형제 요소 간격은 1~3f로 고르지 않게. 0.6s 안에 끝나는 파도는 "한 동작", 그보다 길면 "세는 목록"으로 읽힌다.
- 모든 정보는 다 읽힐 만큼 멈추고, 화면엔 살아 있는 것 하나(아주 느린 확대 1.00→1.04, 그레인)만 남긴다. 멈춘 화면이 3초를 넘기지 않는다.
- 튕김은 늦게, 드물게: 전문가 움직임의 8.8%만 넘침이 있고 정점은 진행 65~70% 지점. 수량·금액에는 넘침 금지. 불투명도·흐림은 항상 임계 감쇠.
