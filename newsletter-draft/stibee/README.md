나머지 이미지 6장은 매거진그린 웹플로 서버의 기사 사진 주소를 그대로 씀.

## 순서

1. **표지 날짜 넣기 (필수).** 표지 이미지 안 날짜가 아직 `2026. 0. 0.`이다. 발송일이 정해지면 표지를 다시 만든다.
2. **주소록 올리기.** 스티비 › 주소록 › 구독자 추가 › 파일 업로드에서 CSV를 올리고 이메일·이름·그룹 열을 연결한다.
3. **이미지 2장 올리기.** 스티비 이미지 업로드(또는 웹플로 에셋)에 표지와 용산 이미지를 올리고, HTML의 `{{COVER_URL}}`, `{{YONGSAN_URL}}`을 그 주소로 바꾼다.
4. **이메일 만들기.** 새 이메일 › 'HTML로 직접 만들기' 템플릿 › HTML 전체를 붙여 넣는다.
5. **제목·발신자.** 제목 예: `그린레터 제1호 · 작가정원 지원금, ㎡로 다시 읽기` / 발신자 이름: 매거진그린
6. **테스트 발송.** 대표 메일로 보내 PC·모바일을 확인한다. 테스트 메일에서는 수신거부·웹에서 보기 링크가 작동하지 않는 것이 정상이다.
7. **발송.** 그룹을 골라 보낸다. 오후 9시~다음 날 오전 8시 발송은 피한다(별도 동의 필요).
