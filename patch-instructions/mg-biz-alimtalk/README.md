# 고객 접수 확인 알림톡 붙이기 (mg-biz)

정원 견적·상담 신청(`POST /leads`)이 접수되면, 신청한 고객 휴대폰으로 카카오 알림톡 접수 확인을 보냅니다.
카카오톡을 쓰지 않는 번호에는 같은 문안을 문자로 대신 보냅니다. 발송사는 솔라피(SOLAPI)입니다.

- 발송은 Turnstile 확인, 같은 IP 10분 3회 제한을 모두 통과해 DB에 저장된 접수에만 갑니다.
  봇이 남의 번호로 문자를 연달아 보내게 만드는 일은 막혀 있습니다.
- 알림톡이 실패해도 접수는 그대로 성공합니다. 실패하면 운영자 텔레그램으로
  "⚠️ 고객 접수 알림톡 발송 실패"가 옵니다.
- 결과는 접수 이력(`lead_events`)에 `alimtalk:ok` 또는 `alimtalk:fail:<코드>`로 남습니다.
- 아래 설정값이 하나라도 비어 있으면 아무것도 보내지 않습니다. 그래서 템플릿 승인 전에 코드를 먼저 배포해도 됩니다.

> 이 저장소에는 mg-biz 원본(`src/worker.js`)이 없어서, 2026-10-26에 운영 중이던 워커 코드를 기준으로 만든 붙여넣기용 패치입니다.

---

## 1. 솔라피·카카오 준비 (사람이 해야 하는 일)

1. **솔라피 가입**(solapi.com), 충전, **발신번호 등록**(문자 대체 발송에 필요)
2. **카카오톡 채널 연동**: 솔라피 콘솔 → 카카오 채널 연동 → 채널 검색용 아이디 입력 → **pfId 발급**
3. **알림톡 템플릿 등록과 검수 요청**. 아래 문안을 **그대로** 등록합니다. 검수는 보통 영업일 1~3일 걸립니다.
   - 카테고리: 서비스이용 > 이용안내/공지 (정보성)
   - 메시지 유형: 기본형

```
[정원 상담 접수 완료]
#{이름}님, 정원 견적·상담 신청이 접수되었습니다.

▶ 접수번호: #{접수번호}

담당 매니저가 신청 내용을 검토한 뒤 입력하신 연락처로 직접 연락드립니다.
현장 조건과 예산을 먼저 듣고, 그에 맞는 진행 방법을 안내해 드립니다.

문의: info@magazinegreen.co.kr

※ 정원 상담을 신청하신 분께 발송되는 안내 메시지입니다.
```

   - 변수 이름 `#{이름}`, `#{접수번호}`는 코드와 똑같아야 합니다. 문안을 고치려면 코드의 `variables`도 같이 고쳐야 합니다.
   - 예산 500만 원 미만 신청(셀프 가이드로 안내)에도 어색하지 않도록, "작가 연결"이라는 약속은 넣지 않았습니다.
4. 검수가 끝나면 **templateId**를 복사합니다.

## 2. 코드 붙이기 (`src/worker.js`)

**(1)** `alimtalk.js` 내용 전체를 `notifyTelegram` 함수 **바로 아래**에 붙입니다.

**(2)** `handleLeadCreate` 안에서 아래 줄을 찾아:

```js
  await notifyTelegram(env, lead);
```

바로 아래에 한 줄을 추가합니다:

```js
  await notifyTelegram(env, lead);
  await sendLeadReceipt(env, lead);
```

`/notify/chgreen`(채널그린 사이트 접수 중계)에는 붙이지 않았습니다. 그쪽은 고객 연락처를 받지 않기 때문입니다.

## 3. 설정값 넣기

```bash
npx wrangler secret put SOLAPI_API_KEY
npx wrangler secret put SOLAPI_API_SECRET
npx wrangler secret put SOLAPI_SENDER      # 등록한 발신번호, 예: 02-1234-5678
npx wrangler secret put KAKAO_PF_ID        # 솔라피에서 발급한 pfId
npx wrangler secret put KAKAO_TEMPLATE_ID  # 검수 완료된 템플릿 ID
npx wrangler deploy
```

## 4. 확인

1. 내 휴대폰 번호로 견적 폼을 한 번 제출합니다.
2. 알림톡이 오는지 확인합니다. 솔라피 콘솔의 메시지 로그에서도 결과를 볼 수 있습니다.
3. 관리자 화면에서 그 접수의 이력에 `alimtalk:ok`가 찍혔는지 봅니다.
4. 카카오톡이 없는 번호로 문자 대체 발송이 되는지도 콘솔 로그로 한 번 확인합니다.
   대체 문자에는 알림톡 템플릿 문안이 들어가야 정상입니다.

## 5. 개인정보처리방침 (배포 전에 꼭)

고객 이름과 휴대폰 번호가 솔라피(와 카카오)로 넘어가므로 **개인정보 처리위탁**에 해당합니다.
처리방침의 위탁 항목에 다음을 추가해 주세요.

| 수탁자 | 위탁 업무 |
|---|---|
| (주)솔라피 | 상담 신청 접수 안내 알림톡·문자 발송 |

접수 확인 안내는 고객이 동의한 "상담·견적 연락" 목적 안에 들어가므로 별도 동의는 필요 없습니다.
다만 처리방침 개정에 맞춰 `CONSENT_VERSION`을 새 날짜로 올려 두는 것이 안전합니다.
